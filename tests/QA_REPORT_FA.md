# گزارش کنترل کیفیت نسخه 0.1.0

تاریخ تهیه: 2026-11-04

## آزمون‌های اجراشده در محیط ساخت

| آزمون | نتیجه |
|---|---|
| بررسی نحو JavaScript با `node --check` | موفق |
| بررسی نحو Service Worker | موفق |
| اعتبارسنجی JSON تنظیمات، manifest و package | موفق |
| بررسی ارجاع فایل‌های HTML به assetها | موفق |
| تجزیه CSS و بررسی خطاهای سطح بالا | بدون خطا |
| ساخت ZIP واقعی DOCX | موفق؛ آرشیو سالم |
| بازکردن DOCX با python-docx | موفق |
| ساخت ZIP واقعی XLSX | موفق؛ آرشیو سالم |
| بازکردن XLSX با openpyxl | موفق؛ چهار شیت قابل خواندن |
| ساخت PDF تصویری A4 و بررسی با pdfinfo | موفق؛ یک صفحه A4 |

## آزمون‌هایی که هنوز باید روی مرورگر و گوشی انجام شوند

- جریان کامل افزودن/ویرایش/حذف فاکتور، مشتری، کالا و هزینه
- ذخیره و بازیابی داده پس از بستن و بازکردن برنامه
- تست چاپ و اشتراک فایل در چند نسخه Android WebView
- بررسی ظاهری فارسی و فونت روی گوشی‌های مختلف
- تست بکاپ رمزنگاری‌شده با رمز صحیح و غلط در مرورگر واقعی
- آزمون آفلاین پس از نصب Service Worker
- آزمون Native پرداخت بازار با حساب آزمایشی و SDK Poolakey
- آزمون سرور بکاپ، مجوز Premium سمت سرور و بازیابی چنددستگاهی

## محدودیت آزمون

اجرای مرورگر headless در محیط ساخت پایدار نشد؛ بنابراین آزمون تعاملی کامل UI در این محیط انجام نشده است. گزارش بالا فقط آزمون‌های فنی قابل اجرا در محیط فعلی را ثبت می‌کند و به معنی تضمین بدون‌باگ بودن یا تأیید کافه‌بازار نیست.
