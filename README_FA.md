# فرنوا — نسخه Premium Preview 0.1.0

اپلیکیشن وب محلی برای مدیریت فاکتورها، هزینه‌ها، مشتریان، کالاها و گزارش‌های مالی. رابط فارسی و راست‌چین است و برای اجرا در مرورگر، PWA و بسته‌بندی با Capacitor آماده شده است.

## امکانات فعلی

- داشبورد با جمع فروش، هزینه عملیاتی، بهای تمام‌شده، سود خالص تخمینی و مطالبات
- نمودار روند ماهانه فروش و هزینه و نمودار ترکیب هزینه‌ها
- ایجاد/ویرایش/حذف فاکتور فروش، پیش‌فاکتور، فاکتور خرید و رسید
- محاسبه ردیف‌ها، تخفیف، ارسال، مالیات، مبلغ پرداختی و مانده
- دفترچه مشتریان و مدیریت کالا/خدمات
- ثبت هزینه با دسته‌بندی
- خروجی واقعی PDF تصویری، PNG، JPG، DOCX و XLSX
- بکاپ محلی رمزنگاری‌شده AES-GCM با KDF از نوع PBKDF2 و بازیابی
- ذخیره‌سازی محلی IndexedDB و کارکرد آفلاین پس از بارگذاری اولیه
- پوسته روشن/تیره و طراحی واکنش‌گرا

## اجرای سریع نسخه وب

پوشه `www` را روی یک میزبان استاتیک HTTPS قرار دهید یا از سرور محلی استفاده کنید:

```bash
npx http-server www -p 4173
```

سپس آدرس `http://localhost:4173` را باز کنید. برای نصب PWA، باید برنامه روی HTTPS یا localhost اجرا شود.

## ساخت پروژه اندروید با Capacitor

پیش‌نیازهای رسمی Capacitor 8 شامل Node.js 22 یا بالاتر، Android Studio و Android SDK است.

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

در Android Studio می‌توانید پروژه را روی گوشی/شبیه‌ساز اجرا کنید. برای ساخت APK آزمایشی:

```bash
cd android
./gradlew assembleDebug
```

در ویندوز:

```powershell
cd android
.\gradlew.bat assembleDebug
```

## کامپایل ابری از طریق GitHub

1. این ZIP را استخراج کنید و تمام فایل‌ها را در یک مخزن GitHub قرار دهید.
2. شاخه اصلی را با نام `main` ایجاد کنید.
3. از تب Actions، گردش‌کار `Build Farnava Android Debug APK` را اجرا کنید.
4. فایل APK آزمایشی در بخش Artifacts همان اجرا قرار می‌گیرد.

این گردش‌کار APK آزمایشی Debug تولید می‌کند، نه نسخه امضاشده انتشار بازار. برای انتشار باید کلید امضای اختصاصی خودتان را امن نگهداری و Release signing را پیکربندی کنید.

## وضعیت اتصال بازار و بکاپ ابری

- پرداخت بازار: هنوز به SDK رسمی Poolakey در لایه Native متصل نشده است. جزئیات در `native/BAZAAR_INTEGRATION_FA.md` آمده است.
- بکاپ ابری: هنوز سرور و احراز هویت راه‌اندازی نشده‌اند. قرارداد API و الزامات امنیتی در `server/README_FA.md` آمده است.
- این نسخه «Premium Preview» است و قفل پرداخت تولیدی ندارد. `DEMO_PREVIEW` صرفاً برای آزمایش رابط است و نباید به‌عنوان اثبات اشتراک در نسخه انتشار استفاده شود.

## نکات مالی و محاسبات

- واحد پیش‌فرض مبالغ «تومان» است.
- مالیات پیش‌فرض صفر است؛ نرخ قانونی را خود کسب‌وکار باید تعیین کند.
- سود خالص در این نسخه تخمینی است: فروش فاکتورهای فروش منهای بهای خرید ثبت‌شده اقلام فروخته‌شده و هزینه‌های ثبت‌شده. این گزارش جایگزین حسابداری رسمی یا اظهارنامه مالیاتی نیست.
- فاکتور خرید در مجموع فروش وارد نمی‌شود؛ مخارج و بهای تمام‌شده در گزارش سود لحاظ می‌شوند.

## تست اولیه

- `node --check www/app.js`
- بازکردن برنامه در Chromium/Chrome و بررسی CRUD فاکتور، مشتری، کالا و هزینه
- آزمایش خروجی PDF/PNG/JPG/DOCX/XLSX با بازکردن فایل‌ها در نرم‌افزار مقصد
- آزمایش بکاپ رمزنگاری‌شده و بازیابی با رمز درست/نادرست
- آزمایش آفلاین پس از نصب Service Worker
- تست پرداخت و بکاپ ابری فقط پس از اتصال واقعی Native/Server

## هشدار انتشار

هیچ نرم‌افزاری را نمی‌توان بدون آزمون روی دستگاه‌ها و نسخه‌های مختلف اندروید «بدون باگ» تضمین کرد. این بسته یک نسخه اولیه قابل اجرا و قابل توسعه است، نه گواهی تأیید کافه‌بازار. پیش از انتشار عمومی باید پرداخت رسمی بازار، API بکاپ، امضای Release، مجوز تجاری فونت‌ها، سیاست حریم خصوصی و آزمون‌های بازار تکمیل شوند.
