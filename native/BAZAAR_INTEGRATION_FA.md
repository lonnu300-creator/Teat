# اتصال رسمی پرداخت کافه‌بازار — فرنوا

این بسته رابط وب را آماده می‌کند؛ پرداخت واقعی عمداً تا زمان اتصال SDK رسمی بازار فعال نیست.

## شناسه‌های پیشنهادی محصول

- `farnava_premium_monthly` — اشتراک ماهانه
- `farnava_premium_yearly` — اشتراک سالانه
- `farnava_premium_lifetime` — خرید دائمی قابلیت‌های آفلاین (در صورت تأیید مدل فروش در پنل بازار)

## الزامات پیاده‌سازی

1. SDK رسمی Poolakey را از مخزن `cafebazaar/Poolakey` دریافت کنید و نسخه پایدار/مجاز را در زمان ادغام از مستندات رسمی بررسی کنید.
2. کد خرید باید در لایه Native اندروید (Kotlin/Java) اجرا شود، نه در JavaScript و نه با شبیه‌سازی پاسخ خرید.
3. پس از اتصال، خریدهای قبلی و اشتراک‌های فعال باید از طریق SDK بررسی و بازیابی شوند.
4. برای بکاپ ابری، سرور باید وضعیت اشتراک را مستقل از کلاینت بررسی کند. هیچ کلید خصوصی یا کلید API بازار نباید در APK یا فایل‌های وب قرار بگیرد.
5. callback جاوااسکریپت باید فقط نتیجه تأییدشده Native را دریافت کند؛ متغیر localStorage یا فلگ `DEMO_PREVIEW` معیار دسترسی تولیدی نیست.

## قرارداد پیشنهادی Bridge

رابط وب در نسخه فعلی entitlement را به‌عنوان «پیش‌نمایش توسعه» نمایش می‌دهد. در نسخه انتشار، یک Capacitor Plugin با نام `FarnavaBilling` ایجاد شود و حداقل این متدها را ارائه کند:

- `getEntitlement()` → `{ premium: boolean, expiresAt?: string, source: 'bazaar' }`
- `purchaseSubscription({ productId })`
- `purchaseLifetime({ productId })`
- `restorePurchases()`

تا وقتی این متدها در Native پیاده‌سازی و با حساب آزمایشی بازار تست نشده‌اند، خرید درون‌برنامه‌ای تکمیل‌شده محسوب نمی‌شود.
